# SheBlooms 🌸
> **Tagline:** *Your body. Your questions. Your learning space.*  
> **Subtitle:** A privacy-conscious menstrual health education platform

---

## 🌺 Overview & Mission
Reliable, understandable menstrual health guidance is fragmented across life stages. Girls feel unprepared for their first period. Women navigate perimenopause and menopause without clear information. SheBlooms provides one welcoming, stigma-free digital space to learn, ask, and understand without hesitation:

- **Private by design:** No mandatory accounts, zero tracking, and no advertising.
- **Multi-stage guidance:** Puberty & First Period, Cycle & Period Care, Perimenopause & Menopause, and Educators & Caregivers.
- **Evidence-informed health guides:** Grounded in public health recommendations from the World Health Organization (WHO) and reproductive health bodies.
- **Gentle AI assistant:** Interactive educational guidance with a built-in reviewed offline knowledge base.

---

## 🚀 Quick Start
Run the following commands in your terminal:

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

Open your browser to: **`http://localhost:5173`**

## 🎨 Design System
- **Color Palette:**
  - Raspberry Pink (`#D6457F`): Primary CTA buttons, key headings
  - Deep Orchid / Mauve (`#8B4F7E`): Card titles, secondary accents
  - Soft Violet (`#9B7FD1`): Accents, cycle markers
  - Lavender Mist (`#EDE5FA`): Ambient background tones
  - Blush (`#FFF1F5`): Page background
  - Petal Pink (`#FFD6E4`): Soft highlights and chips
  - Coral (`#F27A6B`): Medical alerts, "When to see a doctor" callouts
  - Marigold (`#EDB650`): Warm ribbons and star accents
  - Plum Ink (`#3B1F3A`): High-contrast, gentle body typography
- **Typography:** *Playfair Display* for editorial headings, *Quicksand* for friendly accents, and *Nunito / DM Sans* for body text.

---

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS + custom glassmorphism utilities
- **Routing:** React Router v6
- **Animations:** Framer Motion (breathing vector illustrations, fluid navigation indicator, smooth card transitions)
- **Celebrations:** `canvas-confetti`
- **Icons:** `lucide-react`
- **Storage:** Client-side `localStorage` only; no external databases or analytics trackers.
